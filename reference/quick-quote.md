## Flag checklist (⚑ line — only the ones that apply)

- worldwide/national scope on a local or regional client
- in-perpetuity (esp. broadcast) → 2×, push for a term
- category / gaming / finance exclusivity on a long or perpetual deal
- "online ad" vs "non-broadcast" labels conflict — different price basis
- AI / synthetic-voice / voice-training rights
- unlimited lifts / versions — pin to a count
- missing client name · ambiguous deliverable count
- in-game / interactive use = separate licence (SAG interactive / per-hour)

## Calibration (Spencer, since 2026-08-28)

- Marketplace: quote **fair-market-mid to win**, keep a real floor, don't undercut.
- **Worldwide + in-perpetuity for a sub-$1k budget = the trap (Avery, Delta Force). PASS, or quote straight — never take it at their number.**
- Budget ABOVE fair market → max out the budget, quote the ceiling.
- Never fabricate a rate. Never fold the directed session into the read fee.
